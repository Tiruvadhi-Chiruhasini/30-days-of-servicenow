# DAY 5: Who Is Allowed To Touch What?

Imagine Techasya has 10,000 employees.

If everyone gets Admin access...

Congratulations.

The company explodes.

So ServiceNow controls access.

## User

A person.

Examples:

* Chiruhasini
* Manager
* HR Employee

Simple.

## Group

A team.

Examples:

* Service Desk
* Network Team
* HR Team

Think:

Group = Squad

## Role

A superpower badge.

Examples:

itil

admin

approver_user

Roles decide:

"What can this person do?"

## My Memory Trick

User = Person

Group = Team

Role = Permission

## Example

Chiruhasini
↓
Service Desk Team
↓
itil Role

Now she can work on tickets.

## Assignment Groups

When something happens:

"VPN is down"

ServiceNow asks:

"Which team should handle this?"

Answer:

Network Team

That's the Assignment Group.

## Future Techasya Thought

If I build my company someday:

HR should not edit server settings.

Roles make that possible.

Security is basically controlled common sense.
