# DAY 6: Stop Getting Lost In ServiceNow

Today's goal:

Become a ServiceNow GPS.

## Application Navigator

The giant search box.

Can't find something?

Search it.

Examples:

Incident

Users

Catalog

Requests

Easy.

## Lists

Think Excel sheet.

Shows many records.

Example:

INC001

INC002

INC003

All together.

That's a List.

## Forms

Open one record.

Now you see every detail.

That page is a Form.

## My Memory Trick

List = Many

Form = One

## Filters

Magic search.

Example:

Show only Open Incidents

Instead of scrolling through 500 records.

## Personalization

You can customize lists.

Add columns.

Remove columns.

Move columns.

Basically:

"Make the screen less annoying."

## Interview Question

Difference between List and Form?

List:

Many records.

Form:

One detailed record.

## Final Day 6 Goal

Don't be the person clicking randomly.

Be the person who knows exactly where everything lives.

That saves hours in real projects.
