# Day 9: Change Management

Today I explored Change Management.

Organizations constantly need to make changes:

* Upgrade servers
* Deploy new applications
* Modify configurations

But changes can introduce risks.

A small mistake in production can affect thousands of users.

Because of that, changes go through:

Review
→ Approval
→ Implementation
→ Closure

### What clicked for me

Not every technical change should happen immediately.

Planning and approvals exist to reduce risk and avoid unexpected disruptions.

### My takeaway

Good engineering is not just building things.

It is making changes responsibly.
