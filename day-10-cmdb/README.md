# Day 10: CMDB (Configuration Management Database)

Today I learned about CMDB.

Initially it looked complex because of all the relationships involved.

But then I understood its purpose.

CMDB stores information about configuration items such as:

* Servers
* Applications
* Databases
* Network devices

It also stores how they are connected.

Example:

Application
↓
Database
↓
Server

### What clicked for me

Systems are not isolated.

Everything depends on something else.

CMDB helps organizations understand those dependencies.

### My takeaway

CMDB is like a map of an IT ecosystem.

It shows how everything is connected.
