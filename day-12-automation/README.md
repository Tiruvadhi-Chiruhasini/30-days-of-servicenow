# Day 12: Workflows & Automation

Today I explored workflows and automation in ServiceNow.

Without automation:

* Requests are manually assigned
* Approvals are manually tracked
* Notifications are manually sent

This creates delays and inconsistencies.

With workflows:

Request
→ Approval
→ Task Creation
→ Assignment
→ Notification
→ Completion

The system handles repetitive steps automatically.

### What clicked for me

Automation is not about replacing people.

It is about reducing repetitive work and improving efficiency.

### My takeaway

A good workflow turns a complicated process into a predictable and reliable system.
